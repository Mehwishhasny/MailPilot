# MailPilot Pro

**MailPilot Pro** is a Python-based email marketing and campaign management application built with Streamlit, SQLite, and Plotly.

It provides user registration, secure password hashing, contact management, personalized email campaigns, HTML email templates, interactive analytics, and SMTP integration.

Registered users can connect their own supported email provider, test their SMTP connection, and send approved campaigns. SMTP credentials are not stored in the SQLite database.

The application also includes a guest demonstration mode with fictional data, allowing visitors to explore its features without sending real emails.

**Tech Stack:** Python · Streamlit · SQLite · Plotly · HTML/CSS · SMTP
